# 社团文档归档权限系统 · GitHub Pages 部署包

> 定格未来 · 共创无限 — 费县第二中学摄影社 × 信息素养小组
> CP-ABE 密文策略属性加密 · 分级授权 · 行为留痕 · Fluid 主题（与 beixianggumao.github.io 同风格，支持亮/暗双模式）

## 一、这是什么

一个**纯静态单文件应用**（`index.html`，约 660KB，零依赖、零构建）：

- 前端界面部署在 **GitHub Pages**（本包）；
- 所有数据与文档存储在**永硕E盘**（www.beixianggumao.ysepan.com）的「社团文档」目录与
  「WebTemp」数据中转站，通过其开放 CORS 的 API 读写，无需任何自有服务器；
- 加密归档的文档以 **CP-ABE 密文**存放在网盘，按密级属性在浏览器端解密。

## 二、部署到 GitHub Pages（三步）

1. 在 GitHub 新建一个仓库（如 `fzsy-docs`，公开 Private 亦可，Pages 需 Pro 以上才支持私有仓库）。
2. 把本包中的 `index.html` 与 `.nojekyll` 上传到仓库根目录
   （网页端 Add file → Upload files 即可；或 `git add . && git commit && git push`）。
3. 仓库 **Settings → Pages → Build and deployment → Source 选择 `Deploy from a branch`**，
   Branch 选择 `main` 与 `/ (root)`，保存。约一分钟后访问
   `https://<用户名>.github.io/<仓库名>/` 即为系统入口（建议把此链接公布给社员）。

> 更新系统时，只需用新版 `index.html` 覆盖仓库中的同名文件。

## 四、功能一览

- **身份认证**：账号 + SHA-256 加盐口令，未认证不可进入（最低权限为公开级）。
- **文档中心**：目录树（00_公开资料 / 01_全社通文件 / 02_摄影社（摄影·后期·运营）/
  03_信息素养小组（比赛·活动）/ 04_秘书处 / 05_社长室）、上传归档（CP-ABE 加密）、
  版本修改（保留历史）、下载（密文自动解密）、删除（留痕）。
- **多维搜索**：题目 / 批号 / 内容 / 标签 / 上传人 / 归档时间范围，可组合筛选；
  快捷项：今天、近7天、近30天、本学期、批号〔年份〕、文书类；顶栏 ⌕ 全局搜索弹窗。
- **文件批号**：信摄秘〔2026〕X字第NNN号，按文种自动递增；批号规范全文见秘书处目录。
- **权限申请**：无权限目录弹框提交申请 → 社长/两位副社长/秘书处处长在通知中心审批 →
  限时临时授权；运营部视频申请走 运营干事 → 摄影社副社长 → 社长 三级审批链。
- **一键备份**（仅社长与秘书处处长可见）：完整 ZIP 备份（全部数据 + 全部文档）与 JSON 数据备份；
  **可选加密**：① 文档加密状态可选「保持密文（推荐）/ 解密为明文（社长专用，需二次确认）」；
  ② 可设置**备份包密码**，整包 AES-256 加密为 .fzenc 文件，恢复时输入密码，无密码者拿到包也读不出内容；
  支持导入恢复并自动重建索引（明文备份的文档恢复时自动按密级重新加密）；操作写入行为日志。
- **自动备份（数据不丢失保险）**：社长/秘书处处长登录时自动检查，距上次超过 7 天
  即在后台静默执行全量数据备份，存于网盘并滚动保留最近 3 份；可在备份中心一键恢复。
- **数据多级兜底**：网盘最新版 → 本机快照 → 默认结构；网盘读取异常自动回退快照，确保系统可启动、数据不丢失。
- **积分模块**：全员可查总榜/部门榜/明细；调整仅社长在独立面板操作，变动通知本人。
- **管理员面板**（仅社长）：
  - 行为日志：关键词/操作人/结果筛选，**一键导出 CSV**；
  - 账号管理：创建/删除/调整角色/**重置密码（新密码随机生成或自设，明文仅显示一次）**/
    **启用停用**/**编辑账号信息（显示名/姓名/年级班级）**/**群发通知（全员/按角色/按个人）**；
    密码均加盐哈希存储，任何人无法回看原密码，忘记密码由社长重置即掌握新密码；
  - 积分面板、文书生成（自动批号 +【相关账号】占位替换）；
  - **数据与回收站**：数据健康检查（7 个数据文件状态/条目数/最后更新/快照）、
    **全量写回网盘（数据保险）**、**网盘文档可达性抽查**、**回收站（软删除文档恢复/彻底清除）**；
  - 系统设置：社长行为记录开关、数据安全状态（快照/自动备份）、批号计数器、学期末积分清零。
- **令牌自愈**：网盘 API 令牌 72 小时滚动续期（每次打开系统自动续写，
  72 小时内有人访问即永续）；令牌仍有效超过 24 小时时自动跳过续期，**加快启动速度**；
  若链条断裂，按登录页「系统令牌恢复」指引粘贴 jwttk 即可恢复，无需重新部署。
- **性能优化**：启动数据并行加载（一次目录查询 + 全部 JSON 并行直读）、
  写操作合并队列（短窗口多次修改只上传一次）、旧版本异步清理、目录列表缓存。

## 四·补、跨域自适应启动器（重要）

永硕E盘数据接口（c6.ysepan.com）仅对 `*.ysepan.com` 内部来源与 `localhost`
开放浏览器跨域（CORS），对 GitHub Pages 等外部托管平台不开放。因此本包
`index.html` 内置**启动器**，打开时自动探测并二选一：

1. **直连模式**：接口放行当前来源（如本地 localhost）→ 直接运行完整应用；
2. **引擎模式**：当前来源被拦截（GitHub Pages 等）→ 自动全屏加载网盘内的
   应用引擎（`社团文档/99_系统应用/社团文档系统.svg`，运行于 *.ysepan.com
   内部来源，不受限制），地址栏仍是您的 GitHub Pages 域名，体验完全一致，
   右下角提供「新窗口打开」入口。

两种模式数据同源同账号，切换无需任何配置；若未来网盘放行外部来源，
GitHub 版将自动升级为直连模式。

## 五、数据与安全说明

- 网盘管理密码已混淆内嵌于前端用于令牌自愈（学校社团场景下的权衡）。**请勿将本仓库
  之外的网盘敏感资料与本应用混放**；如需吊销，直接在永硕E盘后台修改管理密码。
- .cpabe 文件即使被直接下载也无法读出内容（AES-256-GCM，属性密钥 HKDF 派生）。
- 行为日志（登录/查阅/下载/上传/审批/积分/备份）全量留痕，社长可随时审计。
- 数据可靠性三重保障：① 网盘 WebTemp 带版本（同名旧版本自动清理）；
  ② 浏览器本机快照（网盘异常时自动回退）；③ 7 天周期自动备份（滚动 3 份）。
  重要操作后可再到「管理面板 → 数据与回收站」执行「全量写回网盘」加固。
